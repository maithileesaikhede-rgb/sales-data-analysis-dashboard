# Sales Data Analysis Dashboard

## Project Overview
A sales data analysis project created using Google Sheets.

## Features
- Total Revenue and Profit Analysis
- Product-wise Sales Analysis
- Region-wise Profit Analysis
- Monthly Revenue Trends
- KPI Cards and Dashboard Charts

## Tools Used
- Google Sheets
- Spreadsheet Formulas
- Pivot Tables
- Charts

## Dataset
Sample sales data containing orders, products, regions, quantity, selling price and cost.
